# Context

Swift Music is a Swift 6 value library with 25 source files, 3,349 source LOC, and 110 tests in five Swift Testing suites. It has separate macOS and Swift 6.0 Ubuntu workflows, CodeQL analysis, and an independent push-only DocC Pages pipeline. Before this migration it had no canonical spec or committed SpecSync coverage threshold.
