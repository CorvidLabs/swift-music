# Swift Music

## Purpose

Swift Music is a Sendable Swift 6 value library for Western pitch, interval, scale, chord, progression, rhythm, tempo, and Standard MIDI File operations. It provides equal-temperament frequency conversion, enharmonic note naming, chord voicings and extensions, scale and progression presets, meter utilities, MIDI channel/note/velocity validation, channel-message encoding and parsing, timed tracks, and binary MIDI file round trips across Apple platforms and Linux.

## Invariants

- Pitch-class arithmetic wraps modulo twelve; MIDI notes and velocities are 0...127 and channels are 0...15.
- Notes compare, hash, and equate by absolute MIDI pitch; voicings and event lists preserve their documented ordering rules.
- Scale patterns and chord qualities expose their committed semitone formulas without key-dependent spelling.
- MIDI channel messages use standard status/data-byte layouts; note-on velocity zero parses as note-off.
- Standard MIDI Files use big-endian headers, variable-length delta times, track-name metadata, running-status decoding, and end-of-track events.
- All public values that cross concurrency boundaries are Sendable.

## Error Handling

- Validated MIDI constructors throw `MusicError.invalidMIDI`; unchecked constructors return nil and clamped constructors constrain integers to 0...127.
- MIDI message/file parsing throws `MusicError.parsingError` for empty, incomplete, unknown, truncated, or structurally invalid input.
- Existing theory constructors intentionally accept their raw integer inputs; callers remain responsible for valid scale degrees, octave ranges, positive tempos, and ordered octave ranges.

## Behavioral Examples

- `PitchClass.c.transposed(by: 2)` is D, `Note.middleC.midiNumber` is 60, and `Frequency.fromMIDI(69)` is 440 Hz.
- `Scale.cMajor.pitchClasses` is C-D-E-F-G-A-B; its relative scale is A natural minor and its parallel scale is C natural minor.
- `Chord(root: .c, quality: .major7).pitchClasses` is C-E-G-B, while inversion 1 retains C as root and sets E as slash bass.
- At 120 BPM, a quarter note lasts 0.5 seconds and a whole note lasts 2 seconds.
- A note-on for channel value 0, note 60, and velocity 100 encodes as `90 3C 64`; pitch-bend zero encodes around 14-bit center as `E0 00 40`.
- Encoding then decoding a supported Standard MIDI File preserves its format, ticks-per-quarter-note, track count, names, and supported events.

## Error Cases

- MIDI notes/velocities above 127 and channels above 15 throw `MusicError.invalidMIDI`; their failable unchecked initializers return nil.
- Empty, incomplete, or unknown MIDI messages throw `MusicError.parsingError`.
- Invalid/truncated MIDI file chunks, header identifiers, header lengths, formats, and strings throw `MusicError.parsingError`.
- Scale-degree indexing, reversed octave ranges, nonpositive BPM, and arithmetic overflow remain caller preconditions because the existing public implementation does not validate them.

## Dependencies

- Foundation supplies logarithmic frequency math, binary `Data`, string encoding, and formatting.
- Swift DocC is a development-only package plugin and its Pages deployment remains independent from Trust.

## Testing

The committed Swift Testing suite contains 110 tests in five suites. It covers representative pitch/frequency conversion, scales/modes, chords/inversions/voicings, durations/tempo/meters, MIDI value validation, message bytes and parsing, event ordering, track construction, and Standard MIDI File encode/decode behavior. Native verification runs the full suite on macOS and Swift 6.0 Linux.
